# Hurley Electrical

Static website for Hurley Electrical, the Kempston electrician at 18 Singer Way, Bedford, MK42 7AE.

The company on the Google listing is Hurley Electrical. The limited company is Hurley Electrical Contractors Limited, number 06389639.

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

The public site is https://hurley-electrical.surge.sh. That address is set in `astro.config.mjs`.

## Facts

Copy is limited to what is on the Google listing, Companies House, the BSI emergency-lighting entry, and the company’s old website. Reviews are quoted, including the critical ones.
